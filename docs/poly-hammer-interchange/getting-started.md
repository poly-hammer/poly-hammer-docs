# Getting Started

## Requirements

- **Unreal Engine 5.8+** — Install with Epic Launcher. Download launcher [here](https://store.epicgames.com/download)
- **Fab Account** — Login or sign up [here](https://www.fab.com/)
- **Poly Hammer Interchange Unreal Plugin** — Add to your library on fab.com, then install the plugin to your Unreal Engine project
